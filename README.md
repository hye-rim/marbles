# 🔮 구슬 쏘기

구슬 줄이 길을 따라 구멍으로 굴러와요. 같은 색 구슬을 쏴서 **3개 이상** 이어 붙이면 터져요. 줄이 구멍(💀)에 닿기 전에 모두 없애면 단계 클리어! 8단계.

## 조작
| | 폰 | PC |
|---|---|---|
| 겨누기 | 화면을 누른 채 끌기 | 마우스 움직이기 (← → 로도 돌려요) |
| 발사 | 손 떼기 | 클릭, 스페이스, 엔터 |
| 구슬 바꾸기 | 가운데 대포를 톡 누르기, 또는 아래 「구슬 바꾸기」 버튼 | S, Q |

대포 안의 큰 구슬이 지금 쏠 구슬, 뒤쪽 작은 구슬이 다음 구슬이에요. 점선은 겨눈 방향으로 날아가다 처음 닿는 곳까지 보여 줘요.

## 규칙
- 쏜 구슬은 처음 닿은 구슬 **옆에 끼어들어요**. 끼워 넣으면 앞쪽 줄이 조금 밀려 나가니, 아무 데나 쏘면 구멍이 가까워져요.
- 가운데가 터지면 줄이 **끊어져요**. 앞 토막은 서 있고 뒤 토막이 달려가 붙어요. 붙는 곳의 색이 같으면 또 터지는 **연쇄**! 연쇄마다 점수가 1.5배, 2배…
- 💣 구슬이 터지면 양옆 3개씩 더 터져요. ⏳ 구슬이 터지면 줄이 5초 동안 느려져요. (2단계부터 나와요)
- 쏠 구슬 색은 지금 줄에 남아 있는 색에서만 나와요. 막힐 일은 없어요.
- 점수는 단계가 이어지는 동안 쌓여요. 3개 터뜨리면 30점, 더 많이 터뜨릴수록 보너스. 클리어하면 보너스 100점+.

## 단계
1 첫걸음 · 2 나선 · 3 구불구불 · 4 지그재그 · 5 긴 뱀 · 6 큰 나선 · 7 빽빽한 길 · 8 마지막 길. 뒤로 갈수록 색(3→5가지)과 속도가 늘어요.

## 만든 방식
- `logic.js` — DOM 없는 규칙 (`LOGIC_MB`). 1/60초 한 칸씩 `step()`, 같은 시드·같은 입력이면 항상 같은 결과. 길(둥글게 깎은 꺾은선), 줄 토막과 따라잡기, 끼워 넣기, 터뜨리기, 연쇄, 특수 구슬, 승패.
- `game.js` / `index.html` — 그리기(구슬마다 무늬를 넣어 색을 구분하기 쉽게), 입력(터치·마우스·키보드), 소리.
- 시험: `node --test` (디렉터리). 규칙 시험과, 같은 색을 겨누는 **간단한 봇**(`test/bot.js`)이 앞 단계를 깨는지·뒤 단계가 점점 어려워지는지 확인합니다. 봇 결과를 보려면 `BOT=1 node test/bot.js`.
- 저장: `mbLevel`(열린 단계), `mbBest`(최고 점수), `mbSound`.
